# DSN — موقع الألعاب والأنمي والأفلام

موقع عربي باتجاه RTL بتصميم أحمر وأسود، يعمل كواجهة ثابتة دون خادم أو قاعدة بيانات.

## محتويات الحزمة
- `index.html` — بنية الصفحات والواجهة.
- `styles.css` — التصميم المتجاوب.
- `script.js` — بيانات العناصر، البحث، التصنيفات، والنوافذ التفصيلية.

## تجربة الموقع محليًا
1. فك ضغط ملف ZIP.
2. افتح `index.html` بمتصفح حديث مثل Chrome أو Edge.
3. اتصال الإنترنت مطلوب فقط لتحميل الخطوط الخارجية وفتح روابط المصادر.

## النشر المجاني على GitHub Pages
1. أنشئ حسابًا على GitHub وسجّل الدخول.
2. أنشئ مستودعًا جديدًا (Repository)، مثل `dsn-site`.
3. ارفع الملفات الثلاثة (`index.html`, `styles.css`, `script.js`) إلى جذر المستودع.
4. افتح **Settings → Pages**.
5. تحت **Build and deployment** اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
7. انتظر انتهاء النشر، وسيظهر عنوان الموقع في صفحة Pages، غالبًا بالشكل:
   `https://USERNAME.github.io/dsn-site/`

## بديل: Netlify Drop
يمكنك رفع مجلد الموقع أو ملف ZIP إلى خدمة Netlify Drop بعد تسجيل الدخول، ثم تحصل على رابط مجاني. قد تتغير خطوات واجهة الخدمة مع الوقت.

## تخصيص المحتوى
افتح `script.js` وعدّل مصفوفة `items`. لكل عنصر:
- `category`: استخدم `games` أو `anime` أو `movies`.
- `title`: الاسم.
- `description`: نبذة قصيرة.
- `meta`: قائمة وسوم.
- `url`: رابط رسمي أو مرخص.
- `emoji` و`color`: الشكل الفني للبطاقة.

## ملاحظات
- هذه نسخة أولية ببيانات تجريبية ثابتة؛ لا تحتوي على لوحة إدارة أو قاعدة بيانات.
- الروابط الخارجية يجب مراجعتها دوريًا للتأكد من أنها لا تزال صحيحة ومتاحة.
- لا تستضف أو تعِد نشر مواد محمية بحقوق النشر دون إذن. استخدم مصادر وروابط رسمية أو مرخصة.
- الموقع يستخدم Google Fonts اختياريًا؛ عند تعذر الاتصال بها سيستخدم خطوط النظام.
